# Ankit Kumar — Portfolio

Personal portfolio website for **Ankit Kumar**, a BCA graduate and full-stack developer from Delhi. Built as a single-page, single-file site — no build tools, no dependencies, just HTML/CSS/JS.

🔗 **Live site:** https://ankit-kumar-portfolio-kappa.vercel.app

![Portfolio preview]("https://github.com/user-attachments/assets/eec85140-591c-4af1-9083-b9fff4901b5a")

## Overview

A dark, editorial-style portfolio with a "vitals monitor" visual theme — an animated pulse line, status readouts, and stat cards that tie back to a night-owl developer identity. Built to be edited directly in one file and deployed instantly with zero configuration.

## Sections

- **Hero** — name, tagline, live status row
- **Stats bar** — projects shipped, time in production, commits, coffee count
- **About** — background, education, current focus
- **Internship** — experience card *(placeholder — add your real details)*
- **Projects** — 4 featured project cards *(placeholders — swap in your real work)*
- **Tech stack** — Frontend (HTML, CSS, JavaScript, React.js) and Backend & Database (Java, MySQL)
- **DSA** — problem-solving practice on LeetCode and CodeStudio
- **Contact** — email, resume, and social links (GitHub, LinkedIn, X, Instagram, Discord)

## Tech used

- **HTML5** — single-page structure
- **CSS3** — custom properties for theming, CSS Grid/Flexbox layout, keyframe animations
- **Vanilla JavaScript** — mobile nav toggle, scroll-reveal animations (IntersectionObserver), back-to-top button
- **Google Fonts** — Fraunces (display), IBM Plex Mono (labels/data), IBM Plex Sans (body)

No frameworks, no npm install, no build step required.

## Running locally

Just open the file in a browser:

```bash
git clone https://github.com/AnkitKumar-222/Ankit-Kumar-portfolio.git
cd Ankit-Kumar-portfolio
open index.html   # or double-click the file
```

For live-reload while editing, use the VS Code "Live Server" extension.

## Deploying on Vercel

1. Push this repo to GitHub.
2. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
3. Click **Add New Project** → select this repo.
4. Set **Framework Preset** to `Other`. Leave the build command and output directory blank.
5. Click **Deploy** — your site will be live at a `.vercel.app` URL in seconds.
